🔍 曲譜搜尋與下載

💡 檢索 GitHub 開源樂譜庫中的原生 .musicxml、.xml、.mxl 檔案，譜面記號最完整準確。
⚠️ MIDI 轉譜提醒：MIDI（.mid / .midi）原本是電子音源序列格式，載入時系統會自動以演算法量化並分軌（中央 C 以上為右手、以下為左手）轉成五線譜，拍號、調號與雙手分配可能不如原生 MusicXML 精準。
🌐 免登入外部 MIDI 網站直達（下載 .mid 後點左上角「📂 匯入」即可自動轉譜）： BitMidi (11萬首免費庫) ↗ VGMusic (電玩動漫庫) ↗ KunstDerFuge (古典庫) ↗
